# 🎵 TikTok Downloader

Sebuah website untuk mengunduh **Video, Foto (Slideshow), dan Audio TikTok Tanpa Watermark** langsung dari browser.

## ✨ Fitur

- 🎥 Download video TikTok tanpa watermark
- 🖼️ Download foto/slideshow TikTok
- 📦 Download seluruh foto dalam format `.zip`
- 🎵 Download audio (MP3)
- 📋 Tombol Paste dari Clipboard
- ⚡ Tampilan modern & responsif
- 💻 Tidak memerlukan backend (HTML, CSS, JavaScript)

---

## 📂 Struktur Project

```
tikdown/
│
├── index.html
├── css/
│   └── style.css
└── js/
    └── main.js
```

---

## 🚀 Cara Menjalankan

1. Clone repository

```bash
git clone https://github.com/username/tikdown.git
```

2. Masuk ke folder project

```bash
cd tikdown
```

3. Buka file `index.html` menggunakan browser.
